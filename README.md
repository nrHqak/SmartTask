# Smart Task Distributor

Smart Task Distributor — это WinForms-приложение (C#/.NET Framework 4.8) для умного управления задачами.

## Возможности
- Добавление задач с параметрами: название, длительность, сложность, приоритет.
- Удаление выбранной задачи.
- Очистка списка задач.
- Автоматическая оптимизация порядка выполнения задач.
- Подсчёт общего времени и оценка загруженности.
- Проверка корректности ввода и обработка ошибок.

## Алгоритм оптимизации
1. Получить список задач.
2. Рассчитать вес каждой задачи (`CalculateWeight`).
3. Отсортировать задачи:
   - по приоритету (Высокий > Средний > Низкий),
   - затем по сложности (5 → 1),
   - затем по времени (меньше — раньше).
4. Вывести оптимальный порядок в интерфейс.

## Стек
- C#
- .NET Framework 4.8
- Windows Forms

## Запуск
1. Откройте папку проекта в Visual Studio 2019/2022.
2. Обязательно выполните восстановление пакетов: `dotnet restore` (или **Restore NuGet Packages** в Visual Studio).
3. Соберите проект: `dotnet build` (или Build в Visual Studio).
4. Запустите проект (`F5`).

## Структура
- `TaskItem.cs` — модель задачи и расчет веса.
- `TaskManager.cs` — бизнес-логика управления задачами.
- `MainForm.cs` — пользовательский интерфейс и обработка событий.
- `RoundedButton.cs` — кастомная кнопка со скруглением и hover-эффектом.


## Быстрый запуск в терминале Windows
- Запустите `build.bat`, он выполнит `restore` и затем `build` в правильном порядке.


> Примечание: проект переведён на классический формат `.csproj` для .NET Framework 4.8, чтобы избежать зависимости от `project.assets.json` и ошибки `NETSDK1004` при сборке через MSBuild/Visual Studio без отдельного restore.
